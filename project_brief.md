# My agent: Ballknower (CFB & UFC Watch Guide)
One-liner: A conversational sports intelligence agent that helps fans optimize their weekend viewing with personalized College Football watch guides, live upset/thriller alerts, and UFC fight card breakdowns.

Tool coverage:
- Memory: Remembers favorite teams (Georgia Tech, Fresno State, Notre Dame), viewing preferences (ranked matchups, upset alerts, compelling storylines), timezone, and UFC fighters/weight classes of interest.
- Tools: CFB schedule/broadcast fetcher, live scoreboard & score difference tracker (4th quarter 1-score alerts), UFC card schedule & bout order lookup tool.
- Catalog/UI: Weekend watch guide slate (game times, network/streaming channel, storyline/ranking tags rendered as A2UI match cards or schedule tables) and UFC bout order breakdown cards.
- Image gen: Generates matchup hype posters, custom gameday graphics, or fight promo posters.
- Sandbox: Computes win probabilities, upset index scores, or calculates point differential & clock pacing for thriller alerts.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Live sports score API / ESPN scraper, code sandbox for game thrill-score indexing, background cron or notification alerts for 4th-quarter one-score games.
