# BALLKNOWER

A straightforward Saturday CFB and UFC television guide. Preserve the original retro interface while fetching schedules, results, odds and fight-card information directly from public ESPN feeds. Save favorite teams in the browser. Run locally or on static hosting with no AI usage, API credentials, cloud database or paid server.

The production website is the `docs/` directory. No agent framework, conversational assistant, model-generated prediction, cloud image upload, or billed fallback is part of this application. Missing sports data must be labeled as unavailable.
